## 1. 后台登录与首页

### 1.1 登录

1. 访问管理后台地址：`https://your-domain.com/admin`
2. 输入管理员账号和密码
   - 默认账号：`admin`
   - 默认密码：`admin123`
3. 首次登录后请立即修改密码

### 1.2 Dashboard 首页

登录后进入 Dashboard 页面，展示以下关键数据：

| 模块 | 展示内容 |
|------|---------|
| 用户概览 | 总用户数、今日新增、活跃用户、付费用户 |
| 课程概览 | 总课程数、上架课程、学习人次、收入统计 |
| 考试概览 | 考试场次、参考人次、平均分、通过率 |
| 订单概览 | 今日订单、今日收入、待退款、退款率 |
| 系统状态 | 各服务运行状态、CPU/内存使用率 |

## 2. 用户管理

### 2.1 用户列表

进入「用户管理」->「用户列表」页面，可查看所有注册用户。

**列表字段**：
- 用户ID、头像、昵称、手机号、角色、注册时间、最后登录、状态

**操作功能**：
- 搜索：支持按昵称、手机号、角色筛选
- 查看详情：点击用户查看完整信息
- 编辑：修改用户基本信息
- 禁用/启用：控制用户登录权限
- 重置密码：为用户重置登录密码
- 删除：删除用户（需确认，不可恢复）

### 2.2 角色管理

系统内置四种角色：

| 角色 | 说明 | 权限范围 |
|------|------|---------|
| 超级管理员 | 系统最高权限 | 所有功能 |
| 教师 | 课程和班级管理 | 课程管理、班级管理、作业布置、考试发布 |
| 学员 | 学习和练习 | 课程学习、编程练习、在线考试 |
| 家长 | 查看孩子学习情况 | 学习进度、成绩查看 |

**操作步骤**：
1. 进入「用户管理」->「角色管理」
2. 查看角色列表和对应权限
3. 可修改角色权限（超级管理员角色不可修改）

### 2.3 家长绑定管理

家长账号绑定学员账号后，可查看学员的学习进度和成绩。

**操作步骤**：
1. 进入「用户管理」->「家长绑定」
2. 查看绑定关系列表
3. 支持手动绑定/解绑
4. 家长可绑定多个学员

## 3. 课程管理

### 3.1 课程列表

进入「课程管理」->「课程列表」页面。

**列表字段**：
- 课程封面、课程名称、分类、讲师、价格、学习人次、状态、创建时间

**操作功能**：
- 新建课程：创建新的课程
- 编辑课程：修改课程信息
- 上架/下架：控制课程是否对学员可见
- 删除课程：删除课程（已购买用户不受影响）
- 查看详情：查看课程完整信息和数据统计

### 3.2 创建课程

**操作步骤**：

1. 点击「新建课程」按钮
2. 填写基本信息：
   - **课程名称**：课程标题（必填）
   - **课程分类**：选择课程分类（如 Scratch、Python、C++ 等）
   - **课程封面**：上传课程封面图（建议尺寸 1280x720）
   - **课程简介**：课程描述信息
   - **课程价格**：设置课程售价（0 表示免费）
   - **讲师信息**：关联授课教师
   - **适用年龄**：设置目标年龄段
   - **难度等级**：入门/初级/中级/高级
3. 点击「保存」

### 3.3 章节管理

课程创建后，需要添加章节和视频内容。

**操作步骤**：
1. 进入课程详情页
2. 点击「章节管理」
3. 点击「添加章节」
4. 填写章节信息：
   - **章节标题**：章节名称
   - **章节排序**：拖拽调整顺序
   - **上传视频**：支持 MP4 格式，建议单个视频不超过 500MB
   - **章节描述**：章节内容说明
5. 保存章节

**注意事项**：
- 视频上传后会自动生成水印
- 支持弹幕功能，学员可在学习时发送弹幕
- 视频上传到 MinIO 对象存储

### 3.4 课程数据统计

在课程详情页可查看以下数据：
- 学习人次、完成人次、完成率
- 学员评分、评价列表
- 收入统计（按日/周/月）

## 4. 题库管理

### 4.1 题目列表

进入「题库管理」->「题目列表」页面。

**列表字段**：
- 题目ID、题目类型、难度、编程语言、通过率、创建时间

**题目类型**：
| 类型 | 说明 |
|------|------|
| Scratch 编程题 | 使用 Scratch 编辑器作答 |
| ScratchJr 编程题 | 使用 ScratchJr 编辑器作答 |
| 代码编程题 | 使用代码编辑器作答（支持多种语言） |
| 选择题 | 单选/多选 |

### 4.2 创建编程题

**操作步骤**：

1. 点击「新建题目」
2. 选择题目类型（编程题）
3. 填写题目信息：
   - **题目标题**：题目名称
   - **编程语言**：Python / Java / C++ / JavaScript 等
   - **难度等级**：简单/中等/困难
   - **题目描述**：详细描述题目要求
   - **初始代码**：预填充的代码模板
   - **测试用例**：添加评测测试用例
     - 输入数据
     - 预期输出
     - 是否为隐藏测试用例
   - **时间限制**：代码运行时间限制（秒）
   - **内存限制**：代码运行内存限制（MB）
   - **分数**：题目分值
4. 点击「保存」

### 4.3 测试用例管理

每个编程题需要配置测试用例，用于 Judge0 自动评测：

| 字段 | 说明 |
|------|------|
| 输入数据 | 程序的标准输入 |
| 预期输出 | 程序应产生的标准输出 |
| 是否隐藏 | 隐藏用例不对学员展示 |
| 权重 | 该用例在总分中的权重 |

**操作步骤**：
1. 在题目编辑页面找到「测试用例」区域
2. 点击「添加用例」
3. 填写输入和预期输出
4. 设置是否隐藏
5. 可添加多个测试用例

### 4.4 题目导入/导出

支持批量导入导出题目（JSON 格式），方便题库迁移和共享。

## 5. 考试管理

### 5.1 考试列表

进入「考试管理」->「考试列表」页面。

**列表字段**：
- 考试名称、考试类型、考试时间、参考人数、平均分、状态

**考试类型**：
| 类型 | 说明 |
|------|------|
| 公开考试 | 所有学员可参加 |
| 专属考试 | 指定班级或学员可参加 |
| 模拟考试 | 不计成绩，用于练习 |

### 5.2 创建考试

**操作步骤**：

1. 点击「新建考试」
2. 填写考试基本信息：
   - **考试名称**：考试标题
   - **考试类型**：公开/专属/模拟
   - **考试时间**：开始时间和结束时间
   - **考试时长**：答题时间限制（分钟）
   - **及格分数**：及格线（百分比）
   - **考试说明**：考试注意事项
3. 选择题目：
   - 从题库中选择题目
   - 设置每题分数
   - 可设置题目随机排序
   - 可设置选项随机排序
4. 设置防作弊规则：
   - 切换标签页检测
   - 复制粘贴检测
   - 屏幕录制（可选）
   - 离开页面次数限制
5. 配置专属考试（如为专属考试）：
   - 选择可见班级
   - 或手动添加学员
6. 点击「发布」

### 5.3 考试监控

考试进行中，管理员可实时监控：

- 在线人数
- 提交人数
- 异常行为告警（切换标签页、复制粘贴等）
- 强制交卷（针对异常学员）

### 5.4 考试结束处理

考试结束后：
1. 系统自动批改客观题
2. 编程题提交 Judge0 评测
3. 主观题进入人工阅卷队列
4. 所有题目批改完成后可发布成绩

## 6. 阅卷审核工作台

### 6.1 工作台概览

进入「考试管理」->「阅卷工作台」页面。

**工作台功能**：
- 待阅卷试卷数量
- 已阅卷试卷数量
- 阅卷进度百分比
- 平均评分统计

### 6.2 阅卷操作

**操作步骤**：

1. 在工作台选择待阅卷的考试
2. 系统按顺序展示待阅试卷
3. 查看学员答案：
   - 客观题：显示选择结果和正确答案
   - 编程题：显示代码内容和评测结果
     - 可查看代码差异对比
     - 可查看运行输出和错误信息
     - 可查看测试用例通过情况
4. 对编程题进行人工审核：
   - 确认 Judge0 评测结果
   - 可调整分数（如代码逻辑正确但有细微问题）
   - 填写评语
5. 点击「下一份」继续阅卷

### 6.3 批量操作

- **批量通过**：将所有 Judge0 评测通过的答案标记为正确
- **批量退回**：将异常答案退回给学员重新提交
- **导出阅卷记录**：导出所有阅卷记录（Excel 格式）

## 7. 成绩发布流程

### 7.1 成绩发布前检查

在发布成绩前，请确认：

- [ ] 所有试卷已完成阅卷
- [ ] 编程题评测结果已确认
- [ ] 异常成绩已处理（如零分、满分异常）
- [ ] 成绩统计已核对

### 7.2 发布成绩

**操作步骤**：

1. 进入「考试管理」->「成绩管理」
2. 选择要发布成绩的考试
3. 点击「发布成绩」
4. 确认发布
5. 系统自动：
   - 生成成绩报告
   - 发送通知给所有参考学员
   - 更新学员积分（通过考试获得积分）
   - 更新排行榜

### 7.3 成绩查询与导出

- **查询**：支持按考试、学员、分数范围查询
- **导出**：支持导出为 Excel 格式
- **统计**：查看分数分布图、通过率、平均分等

### 7.4 成绩申诉处理

学员可对成绩发起申诉：

1. 管理员在「成绩管理」中查看申诉列表
2. 查看申诉原因和学员答案
3. 重新审核试卷
4. 维持原判或修改分数
5. 通知学员申诉结果

## 8. 班级管理

### 8.1 班级列表

进入「班级管理」->「班级列表」页面。

**列表字段**：
- 班级名称、授课教师、学员人数、创建时间、状态

### 8.2 创建班级

**操作步骤**：

1. 点击「新建班级」
2. 填写班级信息：
   - **班级名称**：如「2024年春季Scratch入门班」

   - **班级描述**：班级介绍
3. 添加学员：
   - 从学员列表中选择
   - 或批量导入（Excel 格式）
4. 保存

### 8.3 班级操作

- **编辑班级**：修改班级信息和教师
- **添加学员**：向班级中添加新学员
- **移除学员**：从班级中移除学员
- **解散班级**：解散班级（学员数据保留）

## 9. 订单管理

### 9.1 订单列表

进入「订单管理」->「订单列表」页面。

**列表字段**：
- 订单号、用户信息、商品名称、支付方式、金额、状态、创建时间

**订单状态**：
| 状态 | 说明 |
|------|------|
| 待支付 | 订单创建，等待支付 |
| 已支付 | 支付成功 |
| 已关闭 | 超时未支付自动关闭 |
| 退款中 | 退款申请处理中 |
| 已退款 | 退款完成 |
| 退款拒绝 | 退款申请被拒绝 |

### 9.2 订单操作

- **查看详情**：查看订单完整信息
- **退款**：对已支付订单发起退款
  - 填写退款金额（不超过原支付金额）
  - 填写退款原因
  - 系统调用支付平台退款接口
- **导出订单**：导出订单列表（Excel 格式）
- **订单统计**：按日/周/月统计收入

## 10. 营销活动管理

### 10.1 优惠券管理

进入「营销管理」->「优惠券」页面。

**创建优惠券**：
1. 点击「新建优惠券」
2. 填写优惠券信息：
   - **优惠券名称**：如「新用户注册优惠券」
   - **优惠类型**：满减 / 折扣 / 免费体验
   - **优惠金额/折扣**：具体优惠值
   - **使用条件**：满 X 元可用
   - **发放数量**：优惠券总数量
   - **有效期**：开始和结束时间
   - **适用课程**：全部课程或指定课程
3. 保存

**优惠券操作**：
- 发放：手动发放给指定用户
- 批量发放：按条件批量发放（如新注册用户）
- 作废：作废未使用的优惠券
- 统计：查看使用率、核销金额

### 10.2 会员体系

进入「营销管理」->「会员管理」页面。

**会员等级配置**：
| 等级 | 条件 | 权益 |
|------|------|------|
| 普通会员 | 注册即可 | 基础功能 |
| 银牌会员 | 累计消费 500 元 | 95 折优惠 |
| 金牌会员 | 累计消费 2000 元 | 9 折优惠 + 专属课程 |
| 钻石会员 | 累计消费 5000 元 | 85 折优惠 + 全部课程 |

### 12.2 支付设置

| 设置项 | 说明 |

| 支付宝 | 配置支付宝参数（详见支付对接手册） |

| 防暴力破解 | 启用/禁用登录频率限制 |

### 12.5 系统维护

| 操作 | 说明 |
|------|------|
| 数据库备份 | 手动触发数据库备份 |
| 缓存清理 | 清理 Redis 缓存 |
| 日志清理 | 清理过期日志文件 |
| 系统信息 | 查看系统版本、运行时间、资源使用情况 |
