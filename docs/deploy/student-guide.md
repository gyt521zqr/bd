## 1. 注册与登录

### 1.1 注册账号

**操作步骤**：

1. 访问平台地址：`https://your-domain.com`
2. 点击右上角「注册」按钮
3. 填写注册信息：
   - **手机号**：输入手机号码
   - **验证码**：点击「获取验证码」，输入收到的短信验证码
   - **设置密码**：设置登录密码（至少 8 位，包含字母和数字）
   - **确认密码**：再次输入密码
   - **昵称**：设置你的昵称
   - **年龄**：选择你的年龄段
4. 阅读并同意《用户协议》和《隐私政策》
5. 点击「注册」

### 1.2 登录

**操作步骤**：

1. 点击右上角「登录」按钮
2. 输入手机号和密码
3. 点击「登录」

**其他登录方式**：
- 手机验证码登录：输入手机号，获取验证码后直接登录
- 第三方登录：支持微信扫码登录（如已开通）

### 1.3 找回密码

如果忘记密码：

1. 在登录页面点击「忘记密码」
2. 输入注册手机号
3. 获取并输入短信验证码
4. 设置新密码
5. 使用新密码登录

### 1.4 完善个人信息

首次登录后，建议完善个人信息：

1. 点击右上角头像 ->「个人中心」
2. 上传头像
3. 填写个人简介
4. 选择感兴趣的编程方向
5. 保存

## 2. 课程购买与学习

### 2.1 浏览课程

**操作步骤**：

1. 登录后，进入「课程中心」页面
2. 浏览课程列表，可通过以下方式筛选：
   - **课程分类**：Scratch、Python、C++、Java 等
   - **难度等级**：入门、初级、中级、高级
   - **适用年龄**：6-8岁、9-12岁、13-16岁等
   - **价格**：免费、付费
   - **热门推荐**：按学习人数排序
3. 点击课程卡片查看课程详情

### 2.2 课程详情

课程详情页展示以下信息：

| 信息 | 说明 |
|------|------|
| 课程封面 | 课程主视觉图 |
| 课程名称 | 课程标题 |
| 课程简介 | 课程描述和学习目标 |
| 讲师信息 | 授课教师信息 |
| 课程价格 | 课程售价（免费课程显示「免费」） |
| 章节列表 | 所有章节和课时列表 |
| 学员评价 | 其他学员的评价和评分 |
| 学习人数 | 已购买/学习的人数 |

### 2.3 购买课程

**免费课程**：
1. 在课程详情页点击「免费学习」
2. 立即开始学习

**付费课程**：
1. 在课程详情页点击「立即购买」
2. 确认订单信息：
   - 课程名称
   - 课程价格
   - 优惠券（如有可用优惠券可选择）
3. 选择支付方式：
   - **微信支付**：扫码支付
   - **支付宝**：扫码支付
4. 扫描二维码完成支付
5. 支付成功后课程自动开通

### 2.4 开始学习

购买成功后，进入课程学习页面：

**操作步骤**：

1. 在「我的课程」中找到已购课程
2. 点击「继续学习」
3. 视频播放页面功能：
   - **播放/暂停**：控制视频播放
   - **进度条**：拖拽跳转到指定位置
   - **章节切换**：在右侧章节列表中切换章节
   - **弹幕**：可发送弹幕与同学互动
   - **全屏**：全屏观看视频
   - **倍速**：调整播放速度（0.5x / 1.0x / 1.25x / 1.5x / 2.0x）
4. 视频播放完成后，自动标记该章节为「已完成」
5. 系统自动记录学习进度

### 2.5 学习进度

在「我的课程」页面可查看每门课程的学习进度：
- 已完成章节数 / 总章节数
- 学习时长
- 最近学习时间

## 3. 编程练习操作

### 3.1 练习列表

**操作步骤**：

1. 进入「编程练习」页面
2. 浏览题目列表，可按以下条件筛选：
   - **编程语言**：Scratch、Python、Java、C++ 等
   - **难度等级**：简单、中等、困难
   - **题目状态**：未完成、已完成、已通过
   - **课程关联**：按课程筛选
3. 点击题目进入练习页面

### 3.2 Scratch 编程练习

**操作步骤**：

1. 选择 Scratch 类型的题目
2. 查看题目要求：
   - 题目描述
   - 目标效果
   - 评分标准
3. 打开 Scratch 编辑器：
   - **积木区**：左侧显示可用的编程积木
   - **编程区**：中间区域拖拽积木组合程序
   - **预览区**：右侧预览运行效果
4. 根据题目要求，拖拽积木完成编程
5. 点击「运行」按钮预览效果
6. 满意后点击「提交」
7. 系统保存提交记录，等待教师批改

### 3.3 ScratchJr 编程练习

**操作步骤**：

1. 选择 ScratchJr 类型的题目
2. 查看题目要求
3. 打开 ScratchJr 编辑器（适合低龄儿童）：
   - **角色选择**：选择动画角色
   - **编程积木**：拖拽积木控制角色动作
   - **舞台**：预览动画效果
4. 完成编程后点击「提交」

### 3.4 代码编程练习

**操作步骤**：

1. 选择代码编程类型的题目
2. 查看题目描述和要求
3. 打开代码编辑器（Monaco Editor）：
   - **代码编辑区**：编写代码
   - **初始代码**：系统预填充的代码模板
   - **语言切换**：切换编程语言（如题目支持多语言）
4. 编写代码：
   - 支持语法高亮
   - 支持代码自动补全
   - 支持 Ctrl+S 保存草稿
5. 点击「运行」按钮测试代码：
   - 输入测试数据
   - 查看运行输出
   - 查看运行时间和内存使用
6. 调试通过后点击「提交」
7. 系统将代码提交到 Judge0 评测引擎：
   - 自动运行所有测试用例
   - 显示评测结果（通过/未通过）
   - 显示各测试用例的执行结果
8. 如果有未通过的用例，可修改代码后重新提交

### 3.5 查看评测结果

提交后可查看详细评测结果：

| 字段 | 说明 |
|------|------|
| 总体结果 | 通过 / 未通过 / 评测中 |
| 通过用例 | 通过的测试用例数 / 总用例数 |
| 运行时间 | 代码运行耗时 |
| 内存使用 | 代码内存占用 |
| 错误信息 | 如有编译错误或运行错误，显示错误详情 |
| 代码差异 | 与标准答案的代码对比（教师批改后可见） |

### 3.6 提交记录

在题目页面可查看所有提交记录：
- 提交时间
- 评测结果
- 通过用例数
- 得分

## 4. 在线考试流程

### 4.1 查看考试列表

**操作步骤**：

1. 进入「考试中心」页面
2. 浏览可参加的考试列表：
   - **公开考试**：所有学员可参加
   - **专属考试**：仅指定班级学员可参加
3. 查看考试信息：
   - 考试名称
   - 考试时间
   - 考试时长
   - 考试状态（未开始/进行中/已结束）

### 4.2 进入考试

**操作步骤**：

1. 在考试列表中找到目标考试
2. 确认考试状态为「进行中」
3. 点击「进入考试」
4. 阅读考试说明和注意事项
5. 点击「开始考试」

**注意事项**：
- 考试开始后倒计时启动，请在规定时间内完成
- 考试期间请勿切换浏览器标签页（会被系统检测记录）
- 考试期间请勿复制粘贴（会被系统检测记录）
- 建议使用 Chrome 浏览器参加考试

### 4.3 答题操作

**客观题答题**：
1. 在试卷中选择题目
2. 点击选项选择答案
3. 可标记题目以便后续检查
4. 试卷导航栏显示答题进度

**编程题答题**：
1. 在试卷中找到编程题
2. 打开代码编辑器（或 Scratch 编辑器）
3. 编写代码完成题目要求
4. 点击「运行测试」验证代码
5. 确认无误后继续下一题

### 4.4 防作弊监控

考试期间系统会进行以下监控：

| 监控项 | 说明 |
|--------|------|
| 标签页切换 | 检测切换浏览器标签页行为 |
| 复制粘贴 | 检测复制粘贴操作 |
| 离开页面 | 检测离开考试页面的行为 |
| 屏幕录制 | 可选，录制考试过程（需浏览器授权） |

**重要提示**：触发防作弊规则会被记录，教师可在阅卷时查看。频繁触发可能导致成绩无效。

### 4.5 交卷

**手动交卷**：
1. 完成所有题目后，点击「交卷」
2. 系统弹出确认对话框
3. 确认交卷

**自动交卷**：
- 考试倒计时结束，系统自动提交试卷
- 请确保在倒计时结束前完成所有题目

### 4.6 查看成绩

考试结束后：
1. 等待教师批改和发布成绩
2. 成绩发布后，在「考试中心」->「我的成绩」中查看
3. 可查看以下信息：
   - 总分和各题得分
   - 排名
   - 通过/未通过
   - 教师评语
   - 代码评测详情（编程题）

## 6. 家长绑定

### 6.1 绑定说明

家长账号绑定学员账号后，家长可以：
- 查看孩子的学习进度
- 查看孩子的考试成绩
- 查看孩子的积分和勋章
- 接收学习报告通知

### 6.2 学员发起绑定

**操作步骤**：

1. 登录学员账号
2. 进入「个人中心」->「家长绑定」
3. 点击「邀请家长绑定」
4. 系统生成邀请码（6 位数字）
5. 将邀请码告知家长

### 6.3 家长接受绑定

**操作步骤**：

1. 家长注册并登录平台
2. 进入「个人中心」->「绑定孩子」
3. 输入学员提供的 6 位邀请码
4. 确认绑定
5. 绑定成功后，家长可在「孩子学习」页面查看信息

### 6.4 解除绑定

- **学员解除**：在「个人中心」->「家长绑定」中点击「解除绑定」
- **家长解除**：在「个人中心」->「绑定孩子」中点击「解除绑定」

解除绑定后，家长将无法查看学员的学习信息。

## 9. 常见问题

### Q1: 注册时收不到验证码怎么办？

1. 检查手机号是否输入正确
2. 检查手机短信是否被拦截
3. 等待 60 秒后重新获取
4. 如果多次尝试仍收不到，请联系客服

### Q2: 购买课程后看不到怎么办？

1. 在「我的课程」中查看是否已存在
2. 刷新页面重试
3. 检查订单状态是否为「已支付」
4. 如仍无法解决，联系客服处理

### Q3: 编程练习提交后一直显示「评测中」？

Judge0 评测通常需要几秒到几十秒。如果超过 1 分钟仍显示「评测中」，可能是：
- 评测服务繁忙，请稍后查看结果
- 代码存在死循环或内存超限
- 评测服务异常，请联系管理员

### Q4: 考试时误触发了防作弊怎么办？

偶尔触发防作弊规则不会影响成绩。系统会记录触发次数，教师阅卷时会综合考虑。请专注答题，避免频繁切换标签页。

### Q5: 如何查看考试成绩？

成绩需要教师批改并发布后才能查看。在「考试中心」->「我的成绩」中查看。如果成绩已发布但仍看不到，请刷新页面或联系教师。

### Q6: 积分什么时候到账？

积分通常在触发行为后实时到账。如果未到账：
1. 刷新页面查看
2. 在「积分记录」中查看最近的积分变动
3. 如积分确实未到账，联系客服处理

### Q7: 如何邀请好友？

1. 进入「个人中心」->「邀请好友」
2. 获取你的专属邀请链接或邀请码
3. 分享给好友
4. 好友注册并开始学习后，你将获得 30 积分奖励

### Q8: 家长绑定后能看到什么？

家长绑定后可以查看：
- 孩子的课程学习进度
- 孩子的考试成绩和排名
- 孩子的积分和勋章
- 孩子的每日学习时长

家长无法查看：
- 孩子的具体代码内容
- 孩子的聊天消息
- 孩子的支付信息

### Q9: 如何申请退款？

1. 进入「个人中心」->「我的订单」
2. 找到需要退款的订单
3. 点击「申请退款」
4. 填写退款原因
5. 提交申请
6. 等待管理员审核（通常 1-3 个工作日）
7. 审核通过后退款原路返回

注意：课程学习进度超过 50% 可能不支持全额退款。

### Q10: 忘记密码怎么办？

1. 在登录页面点击「忘记密码」
2. 输入注册手机号
3. 获取短信验证码
4. 设置新密码
5. 如果手机号已更换，请联系客服协助处理
