## 1. 教师账号登录

### 1.1 获取账号

教师账号由管理员创建并分配。如果尚未获得账号，请联系系统管理员。

### 1.2 登录步骤

1. 访问平台地址：`https://your-domain.com`
2. 点击右上角「登录」按钮
3. 输入教师账号（手机号）和密码
4. 点击「登录」

### 1.3 首次登录

首次登录后建议：
- 完善个人信息（头像、昵称、简介）
- 修改初始密码
- 绑定手机号和邮箱

## 2. 班级创建和管理

### 2.1 创建班级

**操作步骤**：

1. 登录后，进入「我的班级」页面
2. 点击「创建班级」按钮
3. 填写班级信息：
   - **班级名称**：如「2024年春季Scratch入门班」
   - **班级描述**：班级简介，如适用年龄、学习目标等
   - **班级封面**：上传班级封面图（可选）
   - **最大人数**：班级最大容纳学员数
4. 点击「创建」

### 2.2 添加学员

创建班级后，需要添加学员。支持以下方式：

**方式一：邀请码添加**
1. 在班级详情页，点击「邀请码」
2. 系统生成唯一的班级邀请码
3. 将邀请码发送给学员
4. 学员在「加入班级」页面输入邀请码即可加入

**方式二：手动添加**
1. 在班级详情页，点击「添加学员」
2. 搜索学员（按昵称或手机号）
3. 点击「添加」将学员加入班级

**方式三：批量导入**
1. 在班级详情页，点击「批量导入」
2. 下载导入模板（Excel 格式）
3. 按模板填写学员信息
4. 上传填写好的 Excel 文件
5. 系统自动匹配并添加学员

### 2.3 班级管理操作

| 操作 | 说明 |
|------|------|
| 编辑班级 | 修改班级名称、描述、封面 |
| 查看学员列表 | 查看班级中所有学员信息 |
| 移除学员 | 将学员从班级中移除 |
| 查看班级统计 | 学员总数、活跃度、平均进度 |
| 归档班级 | 学期结束后归档班级数据 |
| 解散班级 | 永久解散班级（数据保留） |

### 2.4 班级公告

教师可在班级中发布公告，通知学员重要信息：

1. 进入班级详情页
2. 点击「发布公告」
3. 填写公告标题和内容
4. 选择是否置顶
5. 点击「发布」

## 3. 作业布置和批改

### 3.1 布置作业

**操作步骤**：

1. 进入「我的班级」页面
2. 选择目标班级
3. 点击「布置作业」
4. 填写作业信息：
   - **作业标题**：如「Scratch 小游戏制作练习」
   - **作业描述**：详细说明作业要求
   - **作业类型**：
     - Scratch 编程作业：学员使用 Scratch 编辑器完成
     - ScratchJr 编程作业：学员使用 ScratchJr 编辑器完成
     - 代码编程作业：学员使用代码编辑器完成
     - 理论作业：选择题/填空题
   - **关联题目**：从题库中选择题目（可选）
   - **截止时间**：设置作业提交截止时间
   - **满分值**：作业满分分数
5. 点击「发布」

### 3.2 查看提交情况

作业发布后，教师可实时查看学员提交情况：

1. 进入「我的班级」->「作业列表」
2. 点击目标作业
3. 查看提交统计：
   - 已提交人数 / 班级总人数
   - 平均得分
   - 提交时间分布

### 3.3 批改作业

**操作步骤**：

1. 在作业详情页，点击「开始批改」
2. 系统按顺序展示学员提交的作业
3. 查看学员答案：
   - **Scratch 作业**：查看 Scratch 项目文件，可在线预览运行效果
   - **代码作业**：查看代码内容、运行结果和 Judge0 评测结果
     - 查看代码差异对比（与标准答案对比）
     - 查看测试用例通过情况
     - 查看运行输出和错误信息
   - **理论作业**：查看选择答案，系统自动批改
4. 进行评分：
   - 确认自动评测结果
   - 可调整分数
   - 填写评语和修改建议
5. 点击「提交评分」进入下一份

### 3.4 批量操作

| 操作 | 说明 |
|------|------|
| 批量通过 | 将所有自动评测通过的作业标记为满分 |
| 批量提醒 | 向未提交学员发送提醒通知 |
| 延长截止时间 | 修改作业截止时间 |
| 导出成绩 | 导出本次作业成绩（Excel 格式） |

### 3.5 作业统计

批改完成后，可查看以下统计数据：
- 分数分布图
- 平均分、最高分、最低分
- 通过率
- 常见错误分析

## 4. 专属考试发布

### 4.1 创建专属考试

教师可为指定班级创建专属考试，仅班级内学员可参加。

**操作步骤**：

1. 进入「我的班级」页面
2. 选择目标班级
3. 点击「发布考试」
4. 填写考试基本信息：
   - **考试名称**：如「Scratch 期中考试」
   - **考试时间**：开始时间和结束时间
   - **考试时长**：答题时间限制（分钟）
   - **及格分数**：及格线（如 60 分）
   - **考试说明**：考试注意事项和规则
5. 选择题目：
   - 从题库中选择题目
   - 设置每题分数
   - 可开启题目随机排序
   - 可开启选项随机排序
6. 设置防作弊规则：
   - 切换标签页检测：开启后学员切换标签页会被记录
   - 复制粘贴检测：开启后禁止复制粘贴
   - 离开页面限制：设置允许离开页面的最大次数
7. 点击「发布」

### 4.2 考试监控

考试进行中，教师可实时监控：

**操作步骤**：
1. 进入「我的考试」页面
2. 点击正在进行的考试
3. 查看监控面板：
   - **在线人数**：当前正在答题的学员数
   - **已交卷人数**：已提交试卷的学员数
   - **异常告警**：显示触发防作弊规则的学员
     - 切换标签页
     - 复制粘贴操作
     - 频繁离开页面
   - **强制交卷**：对异常学员强制提交试卷

### 4.3 考试结束处理

考试结束后：
1. 系统自动批改客观题
2. 编程题提交 Judge0 评测
3. 教师进入阅卷工作台审核编程题
4. 所有题目批改完成后，点击「发布成绩」

### 4.4 成绩查看

成绩发布后：
- 学员可在个人中心查看成绩
- 教师可查看班级成绩统计
- 支持导出成绩报表

## 5. 学生进度查看

### 5.1 班级学习概览

教师可查看班级整体学习进度：

1. 进入「我的班级」-> 选择目标班级
2. 点击「学习进度」
3. 查看以下信息：
   - 每位学员的课程完成进度
   - 作业提交情况
   - 考试成绩
   - 积分排名

### 5.2 个人学习详情

点击学员姓名可查看详细学习记录：

| 模块 | 查看内容 |
|------|---------|
| 课程学习 | 已学课程、学习时长、完成进度 |
| 编程练习 | 提交次数、通过率、薄弱环节 |
| 考试记录 | 参加的考试、成绩、排名 |
| 积分记录 | 获得的积分、勋章 |

### 5.3 学习报告

教师可生成班级学习报告：

1. 进入「我的班级」->「学习报告」
2. 选择时间范围（周/月/学期）
3. 点击「生成报告」
4. 报告内容包括：
   - 班级整体学习情况
   - 学员个人学习数据
   - 课程完成率统计
   - 作业和考试成绩分析
   - 薄弱知识点分析
5. 支持导出为 PDF 格式

### 5.4 薄弱学员识别

系统自动识别学习进度落后的学员：

- 课程完成率低于 50%
- 作业提交率低于 60%
- 考试成绩低于及格线
- 连续 7 天未登录

教师可对薄弱学员发送提醒通知，或安排针对性辅导。

## 6. 成绩导出

### 6.1 导出作业成绩

1. 进入「我的班级」->「作业列表」
2. 选择目标作业
3. 点击「导出成绩」
4. 选择导出格式（Excel）
5. 下载文件

**导出内容**：
- 学员姓名、学号
- 提交时间
- 评分、评语
- Judge0 评测结果（编程作业）

### 6.2 导出考试成绩

1. 进入「我的考试」页面
2. 选择目标考试
3. 点击「导出成绩」
4. 选择导出格式（Excel）
5. 下载文件

**导出内容**：
- 学员姓名、学号
- 总分、各题得分
- 排名
- 答题用时
- 防作弊记录

### 6.3 导出班级综合成绩

1. 进入「我的班级」-> 选择目标班级
2. 点击「综合成绩」
3. 选择时间范围
4. 点击「导出」
5. 下载综合成绩报表

**导出内容**：
- 学员基本信息
- 各课程学习进度
- 各次作业成绩
- 各次考试成绩
- 积分和勋章
- 综合评分

| 类型 | 说明 |

## 8. 常见问题

### Q1: 如何修改班级信息？

进入「我的班级」-> 选择目标班级 -> 点击「编辑」按钮 -> 修改信息 -> 保存。

### Q2: 学员无法加入班级怎么办？

1. 确认邀请码是否正确且未过期
2. 确认班级人数是否已满
3. 确认学员账号状态是否正常
4. 如仍无法解决，联系系统管理员

### Q3: 作业截止后还能提交吗？

默认情况下，截止时间后学员无法提交作业。教师可在作业设置中开启「允许迟到提交」选项，或手动延长截止时间。

### Q4: 如何查看学员的代码提交详情？

在作业批改页面，点击学员姓名即可查看代码内容、运行结果和评测详情。支持代码差异对比功能。

### Q5: 考试中如何处理异常情况？

考试监控页面会实时显示异常行为。教师可以：
- 发送警告给异常学员
- 强制交卷
- 考试结束后标记异常试卷

### Q6: 成绩导出的 Excel 文件格式？

导出的 Excel 文件包含多个 Sheet：
- Sheet 1：成绩汇总
- Sheet 2：各题得分明细
- Sheet 3：学习进度数据

### Q7: 如何联系系统管理员？

通过「消息中心」->「联系管理员」发送消息，或直接联系管理员获取技术支持。
